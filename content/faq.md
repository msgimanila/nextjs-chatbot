

# Intellicaai AI Agents — Frequently Asked Questions

## General AI Agent FAQs

### 1. What is an AI agent?

An AI agent is software that can understand instructions, reason about a task, use tools, access information, and take actions to accomplish a goal. Unlike a traditional chatbot, an agent can do more than simply generate text.

### 2. What is the difference between an AI agent and a chatbot?

A chatbot primarily communicates with users. An AI agent can communicate **and perform tasks** by using tools, APIs, databases, workflows, files, and other connected systems.

### 3. What can an AI agent do?

Depending on its configuration, an AI agent can research information, analyze data, write content, manage workflows, interact with business applications, process documents, answer customers, update records, and automate repetitive work.

### 4. Can AI agents work without human supervision?

Some tasks can be automated, while others should include human approval. Intellicaai Agents can be configured for different levels of autonomy depending on the task and connected tools.

### 5. Can an AI agent use external tools?

Yes. An AI agent can connect to tools and services through APIs, MCP servers, workflows, databases, and other integrations.

### 6. What is MCP?

MCP, or Model Context Protocol, is a standard way for AI systems to connect to external tools and data sources. It allows an agent to discover and use capabilities provided by an MCP server.

### 7. Can AI agents access my company's data?

They can, when you explicitly connect the appropriate data source or application and provide the necessary permissions. Access should be configured according to your organization's security requirements.

### 8. Can AI agents remember information?

Yes. An agent can use different types of memory, including conversation context, user information, documents, databases, and vector-based knowledge stores.

### 9. Can an AI agent learn from my business?

An agent can be provided with your business documents, procedures, knowledge bases, and other approved information. This allows it to use your business context when performing tasks. This is different from automatically retraining the underlying AI model.

### 10. Can multiple AI agents work together?

Yes. Multiple agents can be organized into an agent workflow or multi-agent system where different agents perform specialized roles.

# Pricing & Plans

### 31. How much does an Intellicaai Agent cost?

Pricing depends on the agent, capabilities, integrations, infrastructure, usage, and level of customization. Intellicaai can offer different plans for experimentation, building, deployment, and business use.

### 32. Is there a free Intellicaai plan?

Intellicaai can provide entry-level access for users who want to explore AI agents and workflows before moving to more advanced capabilities. Current plan availability and limits should be checked on the pricing page.

### 33. What is included in the Intellicaai Explorer plan?

The Explorer concept is intended for getting started with AI agents and includes capabilities such as multiple agents, a limited monthly allocation of agent work units, workspace functionality, basic memory, connections, testing, and access to supported workflow capabilities.

### 34. What is the Builder plan?

Builder is designed for users who want to create more advanced AI-agent solutions and includes additional development and data capabilities, such as database and long-term/vector memory functionality depending on the current plan configuration.

### 35. What is the Workforce plan?

Workforce is intended for deploying more complete AI-worker environments, including capabilities associated with Intellicaai's autonomous agent platform and workflow ecosystem.

### 36. What is the Business plan?

The Business tier is intended for organizations requiring more advanced agent, workflow, integration, and deployment capabilities.

### 37. Are AI model costs included?

This depends on the plan and deployment. Some configurations may include model usage, while others may allow customers to provide their own model/API credentials or pay for model usage separately.

### 38. Can I use my own AI model API key?

Depending on the product and deployment, customers may be able to connect their own AI model provider and use their own API credentials.

### 39. Do I pay separately for AI model usage?

Potentially. AI model providers generally charge according to their own usage and pricing structures. Intellicaai pricing may also include platform or agent-related costs.

### 40. What are Agent Work Units?

Agent Work Units are a way of measuring agent activity or usage within an Intellicaai plan. They help establish usage limits without requiring every task to be priced as a separate AI agent.

# Deployment, Memory & Integrations

### 41. Does each Intellicaai Agent have its own memory?

An agent deployment can have its own memory and knowledge environment. The exact architecture depends on the product and deployment configuration.

### 42. Can an agent have more than one type of memory?

Yes. An agent can use different memory mechanisms for different purposes, such as short-term conversation context, persistent user information, structured database records, and vector-based knowledge.

### 43. Can my agent have private company knowledge?

Yes. Private knowledge bases can be configured for an agent so that company information is available to that agent according to the configured access controls.

### 44. Can an agent connect to an MCP server?

Yes. Intellicaai Agents can be configured to work with MCP servers where supported, allowing the agent to access additional tools and data sources.

### 45. Can an agent connect to n8n or Activepieces?

Yes. Workflow automation platforms such as **n8n** and **Activepieces** can be used to extend what an agent can do by providing workflows, integrations, triggers, and actions.

### 46. Can an agent connect to databases?

Yes. Depending on the configuration, agents can work with databases such as PostgreSQL and other supported data stores.

### 47. Can I connect CRM and business applications?

Yes. CRM, email, marketing, storage, ERP, project-management, and other business systems can potentially be connected through APIs, MCP servers, workflow automation, or custom integrations.

### 48. Is my Intellicaai Agent hosted for me?

Intellicaai can provide hosted or deployment-based solutions depending on the product and service arrangement. Deployment architecture can vary according to the customer's requirements.

### 49. Can Intellicaai build an agent specifically for my company?

Yes. Intellicaai can design a specialized AI worker around your company's workflows, data, applications, integrations, and business requirements.

### 50. How do I get started with Intellicaai Agents?

You can start by exploring an existing Intellicaai Agent, testing a specialized AI worker, or discussing a custom deployment. From there, the agent can be configured with the appropriate knowledge, memory, tools, workflows, integrations, and AI models.
